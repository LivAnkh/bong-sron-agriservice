# បងស្រនម៉ាស៉ុនច្រូត (Bong Sron Agricultural Machinery Service)

គេហទំព័រសេវាកម្ម **ច្រូតកាត់ស្រូវ (Kubota DC-70 Pro)** និង **វាយដីត្រាក់ទ័រ (Kubota M6040)** ប្រចាំ **ភូមិព្រៃភ្លង ស្រុកទ្រាំង ខេត្តតាកែវ**។

## របៀបបើកដំណើរការ (How to Run)
1. ពន្លាឯកសារ ZIP នេះទៅក្នុង Folder របស់អ្នក (Extract the ZIP file).
2. ចុចបើកឯកសារ `index.html` ដោយប្រើកម្មវិធី Browser (Chrome, Edge, Safari) ឬបើកតាម **Live Server** ក្នុង VS Code។

## រចនាសម្ព័ន្ធឯកសារ (Folder Structure)
- `index.html` — កូដគេហទំព័រទាំងមូល (HTML + Tailwind CSS + JavaScript)
- `images/kubota-dc70-pro.png` — រូបភាពម៉ាស៊ីនច្រូតស្រូវ Kubota DC-70 Pro
- `images/kubota-m6040.png` — រូបភាពត្រាក់ទ័រ Kubota M6040
- `images/owner.png` — រូបភាពម្ចាស់អាជីវកម្ម បងស្រនម៉ាស៉ុនច្រូត
